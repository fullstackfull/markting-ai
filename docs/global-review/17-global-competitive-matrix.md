## Category placement
Intended: cross-channel "AI media buyer". Truest current fit: an **AI-governed, Arabic/RTL-first,
honesty-disciplined media-buying copilot for MENA** — today pre-commercial (DEMO).

## Direct / adjacent competitors
- **Global direct:** Smartly.io, Skai, Marin, Revealbot/Bïrch, Madgicx.
- **Regional (most dangerous):** Boostline (Arabic-first, Salla/Zid-native, live), Salla Ads (platform-owned, built-in merchant distribution), MIQAS.
- **Adjacent:** Triple Whale / Northbeam (profit + attribution), Motion (creative), Optmyzr / Adalysis (PPC), Supermetrics / Funnel (data), and the native Ads Managers (the free default everyone already uses).

## Where M-AI genuinely leads
Governed single write path (fail-closed preview→human-approval→audit), Arabic/RTL-first product, and
data-quality/honesty discipline (no fabricated numbers, no blended-currency totals, UNKNOWN-gating).

## Where M-AI is behind / exposed
No live product value (intelligence surfaces empty on real accounts; no live model; writes held; commerce
dormant). Demo-grade attribution (ad-side ROAS only vs MTA/MMM). The regional moat is already occupied by
live incumbents (Boostline, platform-owned Salla Ads).

## Defensible differentiation? PARTLY, and eroding
The governance spine + Arabic/RTL + honesty gating is distinct architecture, but it is undefended as a
product because the live capabilities that would make it matter are held/dormant/blocked, and live regional
incumbents already own the Arabic + Salla/Zid wedge it depends on.
