# 00 — Global Product Maturity & Competitive Review: Methodology

## Purpose
An independent council assessment of whether MARKTING-AI is a coherent, globally competitive, professional
AI-powered marketing operating system — evaluating the PRODUCT (what a professional media buyer can actually
accomplish), not only code quality. This is an **assessment gate**: it produces findings and a prioritized
roadmap; it does NOT implement the roadmap.

## Independence & evidence rules
- 16 specialist reviewers worked **independently** before any synthesis; each wrote its own report
  (`01`–`16`). A final council (`20`) challenges and reconciles them with evidence rather than averaging.
- Every claim about MARKTING-AI is **grounded in the actual code/docs** in `fullstackfull/markting-ai`
  (file-path citations), never inferred from names.
- Competitor claims use **live web research** (available in this environment) with source + date; anything
  unverifiable is marked `UNVERIFIED_EXTERNAL_RESEARCH_REQUIRED`. No competitor facts are invented.
- Honesty constraint: the app runs a DEMO runtime over real DB-backed synthetic fixtures; there are **no live
  ad/commerce credentials**, so live provider data is dormant and labelled BLOCKED_EXTERNAL. No reviewer
  credits live validation without live evidence.

## Scoring
Each reviewer scores its relevant subset of 30 dimensions (daily workflow, cross-channel, diagnosis,
recommendations, creative, commerce/profit, attribution, experimentation, planning, account mgmt, agency,
executive, AI, evidence/provenance, integrations, data freshness, data quality, automation safety, governance,
collaboration, alerts, mobile, Arabic/RTL, enterprise, security, auditability, performance/scale,
explainability, workflow coherence, differentiation) on 0–5 (0 absent · 1 prototype · 2 weak · 3 acceptable ·
4 strong · 5 world-class), each with evidence. The synthesis converts the reconciled picture into /100
dimension scores, a competitive tier (0–5), a gap register (P0–P3), a prioritized roadmap (Impact/Confidence/
Reach/Effort/Dependency), and a single direct verdict.

## The critical question
Would an experienced media buyer managing multiple brands and significant spend choose MARKTING-AI **every
day** over native ad platforms + spreadsheets + specialist tools? Answered from evidence, without diplomacy.
