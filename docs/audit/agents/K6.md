## Verdicts

1. **"Green" is being over-read.** The reproducible green figure is `308/32` cloud + `41` core + `10` policy-engine + `53` bridge-subset + `7` host + `176` engine-hermetic. It exercises translation, the two-step gate as a library, i18n parity, the Snapchat wire, and the proposal-only host in demo mode. It does **not** exercise the apply-path authorization, concurrency, report tenant isolation, the engine wire contract at runtime, or any browser/RTL flow. **Tests passing ≠ safe to run real ad spend.** (This is the readiness caveat of `06`, and I affirm it.)
2. **One P1, invisible to every green suite.** The non-atomic apply / double provider write (CC-01) is "single-use" only in a sequential test; four independent runtime reproductions show `applyWriteCalls: 2`. Its regression scenario (two concurrent applies → exactly one write) is MISSING. I vouch **P1** (not P0: default policy coerces creates to PAUSED and the two bridge-mapped tools are idempotent absolute-value updates; duplicate *spend* needs a `create` tool via MCP/REST with `paused_creation:false`).
3. **The engine safety suite is dark where it matters.** 19 of its contract tests are RED in-checkout because the host writes `engine/workspace/KILL_SWITCH`, and `make test` never runs that suite — so a genuine regression in the write-gate/claim/replay tests is indistinguishable from the stale-file artifact. **P2.**
4. **No CI means every "N passed" is a point-in-time, hand-run, drifting-HEAD observation.** Nothing re-runs any command in the inventory on push/PR. **P2/GAP.**
5. **The best isolation evidence exists but is out of band.** D5's two Postgres runs and J2's two-tenant probe are the only executed tenant-isolation/concurrency evidence; none runs in CI and the F-team suites could not reach them. Treat those assertions as VERIFIED_RUNTIME-by-D5/J2, VERIFIED_CODE elsewhere — not as VERIFIED_TEST in the shipped suite.
6. **The Playwright "walkthroughs" in the phase reports are DOCUMENTED_ONLY.** No spec, config, dependency, screenshot, or CI step exists (F3 confirmed Playwright is unresolvable from both trees). Arabic/RTL has only dictionary-parity unit tests. This is a GAP, and the phase-report rows should be relabeled "manual, not repeatable."
