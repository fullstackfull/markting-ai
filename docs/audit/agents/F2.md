## Findings

### F2-01 — The markting engine host writes `engine/workspace/KILL_SWITCH` into the vendored engine tree; 19 upstream engine tests fail in this checkout and `make test` does not notice
- **Severity:** P2  **Classification:** VERIFIED_RUNTIME
- **Evidence:** `services/engine-demo/serve_demo.py:173-180` (`engage_kill_switch` writes the file at `settings.paid_media_kill_switch_path`, resolved against `root`), `:388-389` (called on every boot); `engine/src/paid_media_agent/config.py:158` (default `workspace/KILL_SWITCH`, relative); `engine/src/paid_media_agent/runtime/profiles.py:57-60` (relative path resolved against `skills_root`), `:156` (`skills_root=project_root` in the fixture profile the tests use); `engine/src/paid_media_agent/tools/writes.py:195-203`; commands #3-#8 above; file content and mtime (#15) match the host's string and the Phase 1 work window (Phase 0 report committed `02:07`, Phase 1 commits `12:52`); `engine/.gitignore` line `workspace/KILL_SWITCH` hides it from `git status`.
- **Description:** Running the host from source with the engine checkout as project root (Phase 1 report §2 "Engine host run manually") leaves the kill switch engaged in `engine/`. Upstream's write-flow, live-gate, surface and behavior contract tests then all see `rejected` receipts. The 19 failures disappear when the kill switch path is redirected (#7, #8). UPSTREAM.md says "No file modified" in `engine/` and that is true for tracked files, but the runtime tree is modified. `make test` runs only `services/engine-demo/tests` with pytest, never `engine/tests`, so the regression is invisible to the documented test entry point. This is a reliability defect in the markting tooling and verification story, not in upstream: upstream correctly refuses writes while the kill switch is engaged.
- **Impact:** Anyone running `uv run pytest` in `engine/` after `make`-style local use sees a red upstream safety suite; the likely "fix" (deleting the kill switch) is exactly the action the host relies on for its proposal-only guarantee. The documented claim that upstream suites remain green is false for this checkout.
- **Recommendation:** Have the host default `paid_media_kill_switch_path` (and workspace root) to an absolute location outside `engine/` when `root` is the vendored tree, or document and script a `--project-root` copy; add the upstream engine suite to `make test` (or CI) so pollution is caught; add a check that `engine/workspace/` contains only tracked files before running upstream tests.
